
# 555 Timer and CD4017 LED Chaser PCB Design

## Project Overview
A circular LED Chaser circuit designed using KiCad 10, based on the NE555 timer and CD4017 decade counter ICs.

The project includes circuit schematic design, PCB layout, routing and Gerber generation.

## Tools Used
- KiCad 10
- NE555 Timer IC
- CD4017 Decade Counter

## Project Features
- Circular PCB layout
- Multiple LED outputs
- Schematic capture
- PCB component placement and routing
- Gerber and Excellon drill file generation

## Project Files
| Folder | Contents |
|---|---|
| KiCad_Project | Original KiCad source files |
| Schematic | Schematic PDF |
| PCB_Layout | PCB layout and 3D view images |
| Gerber_Files | Manufacturing Gerber and drill files |

## Design Status

- PCB layout: Completed
- Gerber generation: Completed
